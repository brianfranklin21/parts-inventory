# parts-inventory

A PCB component inventory management web application.

## GitHub Pages

This app is hosted on GitHub Pages. To enable GitHub Pages for this repository:

1. Go to your repository on GitHub
2. Click **Settings** > **Pages**
3. Under **Source**, select **Deploy from a branch**
4. Choose the **main** branch and the **/(root)** folder
5. Click **Save**

The app will be available at `https://<username>.github.io/parts-inventory/`

## Usage

Open `index.html` in a browser to use the application. All data is stored in JSON files in the repository.
